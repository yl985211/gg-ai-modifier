## AI Function Calling System

AI chat supports 8 memory operation tools; the LLM can directly call the real memory engine:

| Tool Name        | Function                                                  | Corresponding MemoryEngine Method             |
| ---------------- | --------------------------------------------------------- | --------------------------------------------- |
| `search_memory`  | Exact/range/AOB search                                    | `searchExact` / `searchByRange` / `searchAob` |
| `read_memory`    | Read value at a specified address                         | `readMemory`                                  |
| `write_memory`   | Write value to address (automatic read-back verification) | `writeMemory`                                 |
| `fuzzy_search`   | Fuzzy search (increased/decreased/changed/unchanged)      | `searchFuzzy`                                 |
| `filter_results` | Secondary filtering within the previous results           | `filterResults`                               |
| `save_address`   | Save address to bookmarks                                 | `saveFavorite`                                |
| `freeze_value`   | Freeze/unfreeze address value                             | `toggleBookmarkFreeze`                        |

**Workflow**: User natural language → LLM decides to call a tool → Executes a real MemoryEngine operation → Returns the result → LLM generates the final reply

**Supported LLMs**: DeepSeek-V3/R1, OpenAI GPT-4o/4/3.5, Xiaomi MiMo, and other models compatible with the OpenAI API

## Chat Rendering System

AI replies are rendered through WebView, supporting mixed output of three content types:

### Rendering Pipeline

```
Raw Markdown → protectLaTeX() protects LaTeX → marked.parse() renders Markdown
    → restoreLaTeX() restores placeholders → Prism.highlight() highlights code
    → katex.render() renders formulas → mermaid.run() renders diagrams
```

### Core Features

- **Root permission required**: Uses a standalone C++ executable to read/write target process memory as Root via `su`
- **Dual-mode architecture**: Main app (Flutter) + overlay (native Android View), state synced via SharedPreferences
- **AI Function Calling**: AI can directly call 8 memory operation functions, realizing "change data by saying one sentence"
- **Markdown/Mermaid/LaTeX rendering**: AI replies support code block highlighting, Mermaid diagrams, and LaTeX formulas
- **Chat rendering system**: katex@0.16.9/auto-render.min.js,katex@0.16.9/katex.min.js,katex@0.16.9katex.min.css,mermaid@8.14.0/mermaid.min.js,marked@4.3.0/marked.min.js
- **Overlay system**: HTML rendering pipeline (marked + KaTeX + Prism.js + mermaid), rendered via WebView

### Local JS/CSS Assets

| Library      | Version  | Files                                                        |
| ------------ | -------- | ------------------------------------------------------------ |
| **KaTeX**    | `0.16.9` | `katex.min.js` + `auto-render.min.js` + `katex.min.css`      |

## Memory Search Engine

### Root Architecture

```
MemoryEngine.kt
    ↓ JSON command (stdin)
RootScanner.kt → su → scanner_root (C++ executable)
    ↓ JSON result (stdout)
MemoryEngine.kt → returns search results
```

### Search Modes

| Mode             | Method                                  | Description                                 |
| ---------------- | --------------------------------------- | ------------------------------------------- |
| Exact search     | `searchExact(value, type)`              | Search for an exact numeric value           |
| Range search     | `searchByRange(min, max, type)`         | Search a numeric range                      |
| AOB search       | `searchAob(pattern)`                    | Search by byte signature/pattern            |
| Fuzzy search     | `searchFuzzy(comparison, type)`         | Increased/decreased/changed/unchanged       |
| Result filtering | `filterResults(addresses, value, type)` | Secondary filtering within existing results |

### Data Types

| Type   | Constant         | Bytes |
| ------ | ---------------- | ----- |
| BYTE   | `gg.TYPE_BYTE`   | 1     |
| WORD   | `gg.TYPE_WORD`   | 2     |
| DWORD  | `gg.TYPE_DWORD`  | 4     |
| QWORD  | `gg.TYPE_QWORD`  | 8     |
| FLOAT  | `gg.TYPE_FLOAT`  | 4     |
| DOUBLE | `gg.TYPE_DOUBLE` | 8     |
